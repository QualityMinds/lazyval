= Lazyval: Compile-Time Code Generator for Domain Primimtives in Java or Kotlin

== What is Lazyval / Motivation

Lazyval is a Java annotation processor & Kotlin symbol processor generating boilerplate code,
often needed when modeling _"Domain Primitives"_, which are simple, domain-specific wrapper types around primitives.
The initial idea was inspired by Scalas https://www.scala-lang.org/api/current/scala/AnyVal.html[Anyval];
even though this works completely differently, it allows you to easily define a wrapper-type which captures
the domain's intent.

NOTE: the term _"Domain Primitive"_ was taken from the book https://www.manning.com/books/secure-by-design[Secure by Design].

Unfortunately, the ecosystem usually requires additional work when modeling custom types, which is
often seen as too much of a burden.

As an example, take a regular project (Quarkus, Spring Boot) with Mapstruct and JPA.
For each custom domain primitive, it is necessary to provide a JPA AttributeConverter to read/write
to the Database, as well as a Mapstruct Mapper definition to wrap/unpack the type.

*Lazyval will, depending on your classpath, generate*:

* *a single Mapstruct-Mapper with mappings for all defined domain primitives*

* *a JPA-AttributeConverter for each domain primitive*

NOTE: for custom generators, see xref:spi:index.adoc[Lazyvals SPI].

== Configuration Options

|===
|Property |Description

|_lazyval.jpa.generatedPackage_
|Specifies the package where the `AttributeConverter` classes are generated to.

|_lazyval.mapstruct.generatedPackage_
|Specifies the package where the `LazyvalMapper` interface is generated to.

|_lazyval.disabledGenerators_
|Comma separated List of Generator-IDs which should not generate output despite being found on the classpath.

|_lazyval.values_
|Comma separated List with FQNs for classes which are not part of the current compilation-unit,
but found on the classpath.

|===
