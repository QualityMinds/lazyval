= Using the Lazyval SPI

To support users with the option to add custom code-generators, an SPI (service-provider-interface) has been added for each processor implementation.
The internal generators use the same mechanism and act as a reference implementation.

CAUTION: The SPI is currently experimental and will change.

== Choosing the right SPI

Lazyval ships two structurally identical SPIs — one per toolchain. Pick the one that matches the source language you want to consume:

|===
|Toolchain |Consumes |SPI package |Maven artifact

|Java Annotation Processing (JSR‑269)
|`.java` sources
|`com.qualityminds.lazyval.processor.spi`
|`com.qualityminds.lazyval:lazyval-processor`

|Kotlin Symbol Processing (KSP2)
|`.kt` sources
|`com.qualityminds.lazyval.ksp.spi`
|`com.qualityminds.lazyval:lazyval-ksp`
|===

IMPORTANT: The SPI has to leak the underlying processing API (`javax.lang.model` vs. KSP `KSClassDeclaration`), so a generator implementation targets exactly one toolchain. If you need to support both, ship two artifacts with the same `generatorId()`.

== Workflow

Regardless of the target toolchain, writing a custom generator follows the same four steps:

. Add the chosen processor artifact as a *compile* dependency.
. Implement the `Generator` interface (`generatorId`, `requiredClasspath`, `supportedOptions`, `generate`).
. Register the implementation in `META-INF/services/` under the SPI's fully-qualified name.
. Add the resulting JAR to the *annotation-processor-classpath* of the consuming project.

Language-specific details, code snippets, and Maven wiring live on the dedicated pages:

* xref:spi:java.adoc[Java SPI]
* xref:spi:kotlin.adoc[Kotlin SPI]

== Runnable examples

The `examples/` folder in the repository contains two end-to-end sample setups — one per toolchain — each with a *generator module* (the SPI implementation) and a *using-project* (the consumer) so you can see the full wiring:

* https://github.com/QualityMinds/lazyval/tree/main/examples/java-spi-dev[`examples/java-spi-dev`] — a Java generator emitting a `Utils` helper class.
* https://github.com/QualityMinds/lazyval/tree/main/examples/kotlin-spi-dev[`examples/kotlin-spi-dev`] — the Kotlin/KSP2 counterpart.
