= Cassandra

Since domain-primitives are complex objects, Cassandra cannot natively map them to CQL column types.
This generator creates DataStax `MappingCodec` implementations that transparently convert between your
domain-primitives and their underlying CQL types when reading from or writing to Cassandra.

When Spring Data Cassandra is detected on the classpath, a dedicated set of Spring `Converter` classes and
an auto-configuration are generated instead (see <<Spring Data>> below).

== Config Options

|===
|Property |Description

|_lazyval.cassandra.package_
|Specifies the package where the `LazyvalCassandraCodecs` class is generated to.
Overrides `lazyval.generators.basePackage`.

|_lazyval.cassandra.quarkus.register_
|Controls whether the Quarkus codec registrar is generated when Quarkus is detected.
Defaults to `true`. Set to `false` to disable automatic registration.

|_lazyval.cassandra_spring_data.package_
|Specifies the package where the Spring Data converter classes are generated to.
Overrides `lazyval.generators.basePackage`.

|===

== Generated Files — Codecs

A single `LazyvalCassandraCodecs` utility class is generated that contains one `MappingCodec` inner class
per domain-primitive. It also exposes an `all()` convenience method to register every codec at once.

[tabs]
====
Java::
+
[source,java]
----
public final class LazyvalCassandraCodecs {
  private LazyvalCassandraCodecs() {
  }

  public static TypeCodec<?>[] all() {
    return new TypeCodec[] {
            new OrderDateCodec(),
            new QuantityCodec(),
            new IsbnCodec()
        };
  }

  static class OrderDateCodec extends MappingCodec<LocalDate, OrderDate> {
    public OrderDateCodec() {
      super(TypeCodecs.DATE, GenericType.of(OrderDate.class));
    }

    @Override
    protected OrderDate innerToOuter(LocalDate value) {
      if (value == null) {
        return null;
      }
      return new OrderDate(value);
    }

    @Override
    protected LocalDate outerToInner(OrderDate value) {
      if (value == null) {
        return null;
      }
      return value.date();
    }
  }

  static class QuantityCodec extends MappingCodec<Integer, Quantity> {
    public QuantityCodec() {
      super(TypeCodecs.INT, GenericType.of(Quantity.class));
    }

    @Override
    protected Quantity innerToOuter(Integer value) {
      if (value == null) {
        return null;
      }
      return new Quantity(value);
    }

    @Override
    protected Integer outerToInner(Quantity value) {
      if (value == null) {
        return null;
      }
      return value.value();
    }
  }

  // ... one codec per domain-primitive
}
----

Kotlin::
+
[source,kotlin]
----
public object LazyvalCassandraCodecs {
  public fun all(): Array<TypeCodec<*>> = arrayOf(
      OrderDateCodec(),
      QuantityCodec(),
      IsbnCodec()
  )

  internal class OrderDateCodec : MappingCodec<LocalDate, OrderDate>(TypeCodecs.DATE, GenericType.of(OrderDate::class.java)) {
    override fun innerToOuter(`value`: LocalDate?): OrderDate? = value?.let { OrderDate(it) }

    override fun outerToInner(`value`: OrderDate?): LocalDate? = value?.value
  }

  internal class QuantityCodec : MappingCodec<Int, Quantity>(TypeCodecs.INT, GenericType.of(Quantity::class.java)) {
    override fun innerToOuter(`value`: Int?): Quantity? = value?.let { Quantity(it) }

    override fun outerToInner(`value`: Quantity?): Int? = value?.value
  }

  // ... one codec per domain-primitive
}
----
====

To manually register the codecs with a `CqlSession`:

[source,java]
----
CqlSession session = CqlSession.builder()
    .addTypeCodecs(LazyvalCassandraCodecs.all())
    .build();
----

The following Java-to-CQL type mappings are supported:

|===
|Java Type |CQL Type

|`String` |TEXT
|`int` / `Integer` |INT
|`long` / `Long` |BIGINT
|`double` / `Double` |DOUBLE
|`float` / `Float` |FLOAT
|`boolean` / `Boolean` |BOOLEAN
|`short` / `Short` |SMALLINT
|`byte` / `Byte` |TINYINT
|`LocalDate` |DATE
|`LocalTime` |TIME
|`Instant` |TIMESTAMP
|`UUID` |UUID
|`BigDecimal` |DECIMAL
|`BigInteger` |VARINT
|`InetAddress` |INET
|`ByteBuffer` |BLOB
|===

Domain-primitives wrapping types not listed above will be skipped by this generator.

== Quarkus

When the Quarkus Cassandra extension (`QuarkusCqlSession`) is detected on the classpath, an additional
`LazyvalCassandraCodecRegistrar` CDI bean is generated. It acts as an `@Alternative` producer that wraps
the default Quarkus session stage and registers all codecs into the `MutableCodecRegistry` before the
session is used by other beans.

This can be disabled by setting `lazyval.cassandra.quarkus.register=false`.

[source,java]
----
@ApplicationScoped
@Alternative
@Priority(1)
public class LazyvalCassandraCodecRegistrar {
  private final CassandraClientProducer delegate;

  @Inject
  public LazyvalCassandraCodecRegistrar(CassandraClientProducer delegate) {
    this.delegate = delegate;
  }

  @Produces
  @ApplicationScoped
  @Unremovable
  public CompletionStage<QuarkusCqlSession> produceCodecAwareSessionStage(
      CassandraClientConfig config, @MainEventLoopGroup EventLoopGroup mainEventLoop) {
    CompletionStage<QuarkusCqlSession> stage = delegate.produceQuarkusCqlSessionStage(config, mainEventLoop);
    return stage.thenApply(session -> {
        MutableCodecRegistry registry = (MutableCodecRegistry) session.getContext().getCodecRegistry();
        registry.register(new LazyvalCassandraCodecs.OrderDateCodec());
        registry.register(new LazyvalCassandraCodecs.QuantityCodec());
        registry.register(new LazyvalCassandraCodecs.IsbnCodec());
        return session;
    });
  }
}
----

No manual registration is needed — the codecs are available as soon as the Cassandra session is injected.

== Spring Data

When Spring Data Cassandra (`CassandraCustomConversions`) is detected on the classpath, a separate set of
Spring `Converter` classes is generated instead of (or in addition to) the raw codecs. For each
domain-primitive a `@ReadingConverter` and a `@WritingConverter` are created, together with a
`@Configuration` class that bundles them into a `CassandraCustomConversions` bean.

[tabs]
====
Java::
+
[source,java]
----
@ReadingConverter
public class IsbnReadConverter implements Converter<String, Isbn> {
    @Override
    public Isbn convert(String source) {
        return Isbn.parse(source);
    }
}

@WritingConverter
public class IsbnWriteConverter implements Converter<Isbn, String> {
    @Override
    public String convert(Isbn source) {
        return source.value();
    }
}
----

Kotlin::
+
[source,kotlin]
----
@ReadingConverter
public class IsbnReadConverter : Converter<String, Isbn> {
  override fun convert(source: String): Isbn = Isbn.parse(source)
}

@WritingConverter
public class IsbnWriteConverter : Converter<Isbn, String> {
  override fun convert(source: Isbn): String = source.value
}
----
====

The generated `@Configuration` class registers all converters as a `CassandraCustomConversions` bean.
When Spring Boot is on the classpath, the bean is annotated with `@ConditionalOnMissingBean` so that
it can be overridden by a custom configuration if needed.

[tabs]
====
Java::
+
[source,java]
----
@Configuration
public class LazyvalCassandraSpringDataConfiguration {
    @Bean
    @ConditionalOnMissingBean
    public CassandraCustomConversions cassandraCustomConversions() {
        List<Converter<?, ?>> converters = List.of(
            new IsbnReadConverter(),
            new IsbnWriteConverter(),
            new QuantityReadConverter(),
            new QuantityWriteConverter()
        );
        return new CassandraCustomConversions(converters);
    }
}
----

Kotlin::
+
[source,kotlin]
----
@Configuration
public class LazyvalCassandraSpringDataConfiguration {
  @Bean
  @ConditionalOnMissingBean
  public fun cassandraCustomConversions(): CassandraCustomConversions {
    val converters = listOf(
            IsbnReadConverter(),
            IsbnWriteConverter(),
            QuantityReadConverter(),
            QuantityWriteConverter()
        )
    return CassandraCustomConversions(converters)
  }
}
----
====

Spring Boot auto-configuration will automatically pick up the `CassandraCustomConversions` bean — no
additional setup is required.
