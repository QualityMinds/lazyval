= Cassandra

Since domain-primitives are complex objects, Cassandra cannot natively map them to CQL column types.
This generator creates DataStax `MappingCodec` implementations that transparently convert between your
domain-primitives and their underlying CQL types when reading from or writing to Cassandra.

NOTE: For Spring Data Cassandra projects, see xref:spring-data.adoc[Spring Data] — a separate generator
produces `@ReadingConverter`/`@WritingConverter` classes and a `CassandraCustomConversions` bean.

IMPORTANT: When `spring-data-cassandra` is on the classpath, the `spring-data` generator supersedes
`cassandra` and this generator is silently dropped from the active set. Lazyval logs an info message
in that case. See xref:spi:index.adoc#superseding-other-generators[Superseding other generators] for details.

== Config Options

|===
|Property |Description

|_lazyval.cassandra.package_
|Specifies the package where the `LazyvalCassandraCodecs` class is generated to.
Overrides `lazyval.generators.basePackage`.

|_lazyval.cassandra.quarkus.register_
|Controls whether the Quarkus codec registrar is generated when Quarkus is detected.
Defaults to `true`. Set to `false` to disable automatic registration.

|_lazyval.cassandra.codecs_
|Comma-separated list of fully qualified `TypeCodec` class names appended to the generated codec set.
Only needed when the defaults don't fit — see <<custom-codecs>>.

|===

== Generated Files — Codecs

A single `LazyvalCassandraCodecs` utility class is generated that contains one `MappingCodec` inner class
per domain-primitive. It also exposes an `all()` convenience method to register every codec at once.

[tabs]
====
Java::
+
[source,java]
----
public final class LazyvalCassandraCodecs {
  private LazyvalCassandraCodecs() {
  }

  public static TypeCodec<?>[] all() {
    return new TypeCodec[] {
            new OrderDateCodec(),
            new QuantityCodec(),
            new IsbnCodec()
        };
  }

  static class OrderDateCodec extends MappingCodec<LocalDate, OrderDate> {
    public OrderDateCodec() {
      super(TypeCodecs.DATE, GenericType.of(OrderDate.class));
    }

    @Override
    protected OrderDate innerToOuter(LocalDate value) {
      if (value == null) {
        return null;
      }
      return new OrderDate(value);
    }

    @Override
    protected LocalDate outerToInner(OrderDate value) {
      if (value == null) {
        return null;
      }
      return value.date();
    }
  }

  static class QuantityCodec extends MappingCodec<Integer, Quantity> {
    public QuantityCodec() {
      super(TypeCodecs.INT, GenericType.of(Quantity.class));
    }

    @Override
    protected Quantity innerToOuter(Integer value) {
      if (value == null) {
        return null;
      }
      return new Quantity(value);
    }

    @Override
    protected Integer outerToInner(Quantity value) {
      if (value == null) {
        return null;
      }
      return value.value();
    }
  }

  // ... one codec per domain-primitive
}
----

Kotlin::
+
[source,kotlin]
----
public object LazyvalCassandraCodecs {
  public fun all(): Array<TypeCodec<*>> = arrayOf(
      OrderDateCodec(),
      QuantityCodec(),
      IsbnCodec()
  )

  internal class OrderDateCodec : MappingCodec<LocalDate, OrderDate>(TypeCodecs.DATE, GenericType.of(OrderDate::class.java)) {
    override fun innerToOuter(`value`: LocalDate?): OrderDate? = value?.let { OrderDate(it) }

    override fun outerToInner(`value`: OrderDate?): LocalDate? = value?.value
  }

  internal class QuantityCodec : MappingCodec<Int, Quantity>(TypeCodecs.INT, GenericType.of(Quantity::class.java)) {
    override fun innerToOuter(`value`: Int?): Quantity? = value?.let { Quantity(it) }

    override fun outerToInner(`value`: Quantity?): Int? = value?.value
  }

  // ... one codec per domain-primitive
}
----
====

To manually register the codecs with a `CqlSession`:

[source,java]
----
CqlSession session = CqlSession.builder()
    .addTypeCodecs(LazyvalCassandraCodecs.all())
    .build();
----

The following Java-to-CQL type mappings are supported:

|===
|Java Type |CQL Type

|`String` |TEXT
|`int` / `Integer` |INT
|`long` / `Long` |BIGINT
|`double` / `Double` |DOUBLE
|`float` / `Float` |FLOAT
|`boolean` / `Boolean` |BOOLEAN
|`short` / `Short` |SMALLINT
|`byte` / `Byte` |TINYINT
|`LocalDate` |DATE
|`LocalTime` |TIME
|`Instant` |TIMESTAMP
|`UUID` |UUID
|`BigDecimal` |DECIMAL
|`BigInteger` |VARINT
|`InetAddress` |INET
|`ByteBuffer` |BLOB
|===

Domain-primitives wrapping types not listed above will be skipped by this generator.

== Framework Integration

=== Quarkus

When the Quarkus Cassandra extension (`QuarkusCqlSession`) is detected on the classpath, an additional
`LazyvalCassandraCodecRegistrar` CDI bean is generated. It acts as an `@Alternative` producer that wraps
the default Quarkus session stage and registers all codecs into the `MutableCodecRegistry` before the
session is used by other beans.

This can be disabled by setting `lazyval.cassandra.quarkus.register=false`.

[source,java]
----
@ApplicationScoped
@Alternative
@Priority(1)
public class LazyvalCassandraCodecRegistrar {
  private final CassandraClientProducer delegate;

  @Inject
  public LazyvalCassandraCodecRegistrar(CassandraClientProducer delegate) {
    this.delegate = delegate;
  }

  @Produces
  @ApplicationScoped
  @Unremovable
  public CompletionStage<QuarkusCqlSession> produceCodecAwareSessionStage(
      CassandraClientConfig config, @MainEventLoopGroup EventLoopGroup mainEventLoop) {
    CompletionStage<QuarkusCqlSession> stage = delegate.produceQuarkusCqlSessionStage(config, mainEventLoop);
    return stage.thenApply(session -> {
        MutableCodecRegistry registry = (MutableCodecRegistry) session.getContext().getCodecRegistry();
        registry.register(new LazyvalCassandraCodecs.OrderDateCodec());
        registry.register(new LazyvalCassandraCodecs.QuantityCodec());
        registry.register(new LazyvalCassandraCodecs.IsbnCodec());
        return session;
    });
  }
}
----

No manual registration is needed — the codecs are available as soon as the Cassandra session is injected.

[[custom-codecs]]
[appendix]
== When the defaults aren't enough

The default Java-to-CQL mapping above covers the types most domain-primitives wrap. Domain-primitives
wrapping types outside that table are skipped by the generator — `registry.codecFor(...)` would fail at
runtime if a codec for the wrapped type isn't registered.

Plug in a custom codec via `lazyval.cassandra.codecs` when:

* **the wrapped type isn't in the default mapping** — e.g. wrapping `java.net.URI`, `java.util.Locale`,
  or a third-party value type.
* **a different CQL representation is needed** — e.g. storing `LocalDate` as `TEXT` (ISO-8601) instead of
  the default `DATE`, to keep cqlsh-rendered values human-readable or to dodge driver-version mismatches
  on `LocalDate` encoding.

User-supplied codecs are appended to `LazyvalCassandraCodecs.all()` (and to the Quarkus registrar's
`register(...)` calls) _after_ the generated codecs, so DataStax's last-registered-wins resolution picks
them when both target the same Java type.

=== Example: store `LocalDate` as an ISO string

[tabs]
====
Java::
+
[source,java]
----
public class IsoStringOrderDateCodec extends MappingCodec<String, OrderDate> {

    public IsoStringOrderDateCodec() {
        super(TypeCodecs.TEXT, GenericType.of(OrderDate.class));
    }

    @Override
    protected OrderDate innerToOuter(String value) {
        return value == null ? null : new OrderDate(LocalDate.parse(value));
    }

    @Override
    protected String outerToInner(OrderDate value) {
        return value == null ? null : value.date().toString();
    }
}
----

Kotlin::
+
[source,kotlin]
----
class IsoStringOrderDateCodec :
    MappingCodec<String, OrderDate>(TypeCodecs.TEXT, GenericType.of(OrderDate::class.java)) {
    override fun innerToOuter(value: String?): OrderDate? = value?.let { OrderDate(LocalDate.parse(it)) }
    override fun outerToInner(value: OrderDate?): String? = value?.value?.toString()
}
----
====

Register via:

[tabs]
====
Maven (Java APT)::
+
[source,xml]
----

----

Maven (KSP)::
+
[source,xml]
----

    <lazyval.cassandra.codecs>com.example.IsoStringOrderDateCodec</lazyval.cassandra.codecs>

=== Validation rules

Each FQN passed to `lazyval.cassandra.codecs` is checked at compile time:

* the class must exist
* implement `com.datastax.oss.driver.api.core.type.codec.TypeCodec`
* be accessible from the package where `LazyvalCassandraCodecs` is written
* declare a no-arg constructor with at least the same visibility.

The build fails with one error per offending FQN.

Accessibility covers more than `public`. In Java, package-private is fine when the codec lives in the
same package as the generated configuration. In Kotlin, `internal` is fine when the codec is declared
in the current compilation module; Java package-private follows the same-package rule. This lets users
co-locate codecs with the generated configuration and keep them out of the module's public API.

=== Override semantics — last-wins

DataStax resolves codecs by registration order: when two codecs target the same Java type, the one
registered last wins. The generator emits user codecs after the generated ones in both
`LazyvalCassandraCodecs.all()` and the Quarkus registrar's `register(...)` sequence, so a user codec
overrides the generated one for the same target type. At class-load time, an `INFO`-level message via
`System.Logger` names the user codec and the generated codec it replaces, matching the
xref:mongodb.adoc#custom-codecs[Mongo last-wins] semantics.
