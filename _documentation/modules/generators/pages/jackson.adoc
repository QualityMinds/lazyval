= Jackson

Since domain-primitives are complex objects, (not primitives from a language perspective), they would usually serialize
to JSON as objects rather than values, which just creates overhead on the wire and makes consumption more complex.

This generator registers a custom Jackson module which will make sure that each domain-primitive is serialized as a
simple value and deserializing uses the proper construction method.

Since there are subtle differences from Jackson-2 to Jackson-3, Lazyval ships two dedicated generators for Java as well
as Kotlin.

A domain-primitive is read and written the way the mapper reads and writes its payload type. Jackson calls
`createContextual` on the registered (de)serializer once per mapper and property, before the first value; the
generated one looks up Jackson's own (de)serializer for the payload type there, via the `SerializerProvider` /
`DeserializationContext`, and returns a new instance holding it. So whatever the application configured for the
payload type applies to the domain-primitive too: a (de)serializer it registered for `String`, e.g. one that trims
or sanitizes input or masks output, a config override such as a `LocalDate` format, and a `@JsonFormat` on the
property. Each mapper resolves its own, so nothing one mapper resolved reaches another.

A primitive payload is the one shortcut. The generated serializer writes it directly through `JsonGenerator`, and
the deserializer reads it directly through `JsonParser` if the current token is the one Jackson itself reads
directly for that type, e.g. `VALUE_NUMBER_INT` for an `int`. Any other token is handed to Jackson's own
deserializer for the payload type. Jackson's coercion rules then decide what is still accepted (by default `"7"`
for an `int`), and anything else, such as an object, an array or `true` for an `int`, fails with a
`MismatchedInputException` carrying the property path. A (de)serializer the application registers for a primitive
type is therefore not consulted for the values the shortcut handles.

NOTE: Jackson and JSON-B address the same problem from two different ecosystems. If your application uses
Jakarta JSON-B instead of (or in addition to) Jackson, see xref:jsonb.adoc[JSON-B].

Java (Jackson 2.x)::

[source, java]
----
@Generated(...)
public class LazyvalJacksonModule extends SimpleModule {
  public LazyvalJacksonModule() {
    super("LazyvalJacksonModule", Version.unknownVersion());
  }

  @Override
  public void setupModule(Module.SetupContext context) {
    super.setupModule(context);
    SimpleSerializers sers = new SimpleSerializers();
    SimpleDeserializers desers = new SimpleDeserializers();
    sers.addSerializer(OrderDate.class, OrderDateSerializer.INSTANCE);
    sers.addSerializer(Quantity.class, QuantitySerializer.INSTANCE);
    sers.addSerializer(Isbn.class, IsbnSerializer.INSTANCE);
    desers.addDeserializer(OrderDate.class, OrderDateDeserializer.INSTANCE);
    desers.addDeserializer(Quantity.class, QuantityDeserializer.INSTANCE);
    desers.addDeserializer(Isbn.class, IsbnDeserializer.INSTANCE);
    context.addSerializers(sers);
    context.addDeserializers(desers);
  }

  // Primitive wrapper: direct write through the generator.
  static class QuantitySerializer extends StdSerializer<Quantity> {
    static final QuantitySerializer INSTANCE = new QuantitySerializer();

    protected QuantitySerializer() {
      super(Quantity.class);
    }

    @Override
    public void serialize(Quantity value, JsonGenerator gen, SerializerProvider provider) throws
        IOException {
      gen.writeNumber(value.value());
    }
  }

  // Any other wrapper: the mapper's own serializer for the payload type, resolved per mapper and property.
  static class OrderDateSerializer extends StdSerializer<OrderDate> implements ContextualSerializer {
    static final OrderDateSerializer INSTANCE = new OrderDateSerializer(null);

    private final JsonSerializer<Object> innerSerializer;

    protected OrderDateSerializer(JsonSerializer<Object> innerSerializer) {
      super(OrderDate.class);
      this.innerSerializer = innerSerializer;
    }

    @Override
    public JsonSerializer<?> createContextual(SerializerProvider provider, BeanProperty property)
        throws JsonMappingException {
      return new OrderDateSerializer(provider.findContentValueSerializer(LocalDate.class, property));
    }

    @Override
    public void serialize(OrderDate value, JsonGenerator gen, SerializerProvider provider) throws
        IOException {
      innerSerializer.serialize(value.date(), gen, provider);
    }
  }

  // IsbnSerializer: the same, with the mapper's serializer for String.

  // Primitive wrapper: direct read for the expected token, the mapper's int deserializer for any other.
  static class QuantityDeserializer extends StdDeserializer<Quantity> implements ContextualDeserializer {
    static final QuantityDeserializer INSTANCE = new QuantityDeserializer(null);

    private final JsonDeserializer<Object> innerDeserializer;

    protected QuantityDeserializer(JsonDeserializer<Object> innerDeserializer) {
      super(Quantity.class);
      this.innerDeserializer = innerDeserializer;
    }

    @Override
    public JsonDeserializer<?> createContextual(DeserializationContext ctxt, BeanProperty property)
        throws JsonMappingException {
      return new QuantityDeserializer(ctxt.findContextualValueDeserializer(ctxt.constructType(int.class), property));
    }

    @Override
    public Quantity deserialize(JsonParser p, DeserializationContext ctxt) throws IOException,
        JacksonException {
      int value;
      if (p.isExpectedNumberIntToken()) {
        value = p.getIntValue();
      } else {
        value = (Integer) innerDeserializer.deserialize(p, ctxt);
      }
      return new Quantity(value);
    }
  }

  // Any other wrapper: the mapper's own deserializer for the payload type, resolved per mapper and property.
  static class IsbnDeserializer extends StdDeserializer<Isbn> implements ContextualDeserializer {
    static final IsbnDeserializer INSTANCE = new IsbnDeserializer(null);

    private final JsonDeserializer<Object> innerDeserializer;

    protected IsbnDeserializer(JsonDeserializer<Object> innerDeserializer) {
      super(Isbn.class);
      this.innerDeserializer = innerDeserializer;
    }

    @Override
    public JsonDeserializer<?> createContextual(DeserializationContext ctxt, BeanProperty property)
        throws JsonMappingException {
      return new IsbnDeserializer(ctxt.findContextualValueDeserializer(ctxt.constructType(String.class), property));
    }

    @Override
    public Isbn deserialize(JsonParser p, DeserializationContext ctxt) throws IOException,
        JacksonException {
      String value = (String) innerDeserializer.deserialize(p, ctxt);
      return Isbn.parse(value);
    }
  }

  // OrderDateDeserializer: the same, with the mapper's deserializer for LocalDate.
}

Kotlin (Jackson 3.x)::
+
[source,kotlin]
----
@Generated(...)
public class LazyvalJacksonModule : SimpleModule("LazyvalJacksonModule", Version.unknownVersion()) {
  override fun setupModule(context: JacksonModule.SetupContext) {
    super.setupModule(context)
    val sers = SimpleSerializers()
    val desers = SimpleDeserializers()
    sers.addSerializer(OrderDate::class.java, orderDateSerializer)
    sers.addSerializer(Quantity::class.java, quantitySerializer)
    sers.addSerializer(Isbn::class.java, isbnSerializer)
    desers.addDeserializer(OrderDate::class.java, orderDateDeserializer)
    desers.addDeserializer(Quantity::class.java, quantityDeserializer)
    desers.addDeserializer(Isbn::class.java, isbnDeserializer)
    context.addSerializers(sers)
    context.addDeserializers(desers)
  }

  public companion object {
    private val orderDateSerializer: OrderDateSerializer = OrderDateSerializer()
    private val quantitySerializer: QuantitySerializer = QuantitySerializer()
    private val isbnSerializer: IsbnSerializer = IsbnSerializer()
    private val orderDateDeserializer: OrderDateDeserializer = OrderDateDeserializer()
    private val quantityDeserializer: QuantityDeserializer = QuantityDeserializer()
    private val isbnDeserializer: IsbnDeserializer = IsbnDeserializer()
  }

  // Primitive wrapper: direct write through the generator.
  private class QuantitySerializer : StdSerializer<Quantity>(Quantity::class.java) {
    override fun serialize(
      `value`: Quantity,
      gen: JsonGenerator,
      ctx: SerializationContext,
    ) {
      gen.writeNumber(value.value)
    }
  }

  // Any other wrapper: the mapper's own serializer for the payload type, resolved per mapper and property.
  private class OrderDateSerializer(
    private val innerSerializer: ValueSerializer<Any>? = null,
  ) : StdSerializer<OrderDate>(OrderDate::class.java) {
    override fun createContextual(ctx: SerializationContext, `property`: BeanProperty?): ValueSerializer<*> = OrderDateSerializer(ctx.findContentValueSerializer(LocalDate::class.java, property))

    override fun serialize(
      `value`: OrderDate,
      gen: JsonGenerator,
      ctx: SerializationContext,
    ) {
      checkNotNull(innerSerializer).serialize(value.value, gen, ctx)
    }
  }

  // IsbnSerializer: the same, with the mapper's serializer for String.

  // Primitive wrapper: direct read for the expected token, the mapper's Int deserializer for any other.
  private class QuantityDeserializer(
    private val innerDeserializer: ValueDeserializer<Any>? = null,
  ) : StdDeserializer<Quantity>(Quantity::class.java) {
    override fun createContextual(ctx: DeserializationContext, `property`: BeanProperty?): ValueDeserializer<*> = QuantityDeserializer(ctx.findContextualValueDeserializer(ctx.constructType(Int::class.java), property))

    override fun deserialize(p: JsonParser, ctx: DeserializationContext): Quantity {
      val value = if (p.isExpectedNumberIntToken) {
        p.intValue
      } else {
        checkNotNull(innerDeserializer).deserialize(p, ctx) as Int
      }
      return Quantity(value)
    }
  }

  // Any other wrapper: the mapper's own deserializer for the payload type, resolved per mapper and property.
  private class IsbnDeserializer(
    private val innerDeserializer: ValueDeserializer<Any>? = null,
  ) : StdDeserializer<Isbn>(Isbn::class.java) {
    override fun createContextual(ctx: DeserializationContext, `property`: BeanProperty?): ValueDeserializer<*> = IsbnDeserializer(ctx.findContextualValueDeserializer(ctx.constructType(String::class.java), property))

    override fun deserialize(p: JsonParser, ctx: DeserializationContext): Isbn {
      val value = checkNotNull(innerDeserializer).deserialize(p, ctx) as String
      return Isbn.parse(value)
    }
  }

  // OrderDateDeserializer: the same, with the mapper's deserializer for LocalDate.
}

====

The module is registered via ServiceLoader `META-INF\services\com.fasterxml.jackson.databind.Module` (Jackson 2.x) or
`META-INF\services\tools.jackson.databind.JacksonModule` (Jackson 3.x)  which is written to the compiler output
folder. This way other frameworks like RestAssured will also pick it up.

== Framework Integration

=== Quarkus

In case Quarkus is detected, the module will be registed as `ObjectMapperCustomizer` and `@Singleton` bean.
See https://quarkus.io/guides/rest-json#json[Quarkus docs] for details.

[source,java]
----
@Singleton
public class LazyvalJacksonModule extends SimpleModule implements ObjectMapperCustomizer {

  @Override
  public void customize(ObjectMapper objectMapper) {
    objectMapper.registerModule(this);
  }

  // ...
}
----

=== Quarkus-Redis

By default, Quarkus falls back to a JsonCodec for Redis when discovering custom types, meaning that JSON strings
are serialized to byte[]. Since the LazyvalJacksonModule already registers SerDes for each domain-primitive, Quarkus-Redis
works out of the box.

NOTE: in case binary compatibility with external services is needed for Redis, just register a custom codec following
the official Quarkus docs.

=== Spring

Spring will load the Module via the ServiceLoader file.
